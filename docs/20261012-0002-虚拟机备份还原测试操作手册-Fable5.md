# 虚拟机备份还原测试操作手册（给 AI 直接照做）

> 写给：**要在本项目上做备份/还原实机测试的其它 AI 代理**。
> 目的：把"怎么驱动虚拟机 + 怎么让程序真的跑一次备份/还原 + 怎么验证"写成
> 可照抄的步骤，重点解决 **AI 操作虚拟机时反复踩的坑**。
> 环境：macOS 宿主 + Parallels Desktop，客体是名为 `Windows 11` 的 ARM64 测试机。
> 本手册所有命令在 macOS 终端里跑；客体内命令一律通过 `prlctl exec` 下发。

---

## 零、最重要的三个坑（不看这节必卡）

1. **`Pause idle` 会让 `prlctl exec` 随机超时**。测试 VM 默认 `Pause idle: on`，
   会在你两条命令的间隙把 VM 自动暂停，下一条 `prlctl exec` 报
   `Unable to open new session in this virtual machine...`。这**不是**通道坏了，
   是 VM 睡着了。开工前先关掉，且**每次快照回滚后要再关一次**（见坑 3）：
   ```bash
   prlctl set "Windows 11" --pause-idle off
   ```
   遇到上面那条报错先 `prlctl list -i "Windows 11" | grep -E "State:|Pause idle"`，
   若 `State: paused` 就 `prlctl resume "Windows 11"`，不要重启整个 VM。

2. **客体里的 GUI 窗口你点不到、也枚举不到**。`prlctl exec` 跑在 Session 0 的
   服务窗口站（`Service-0x0-3e7$`），GUI 在 Session 1 的 `WinSta0`。
   `FindWindow`/`EnumWindows`/`Get-Process.MainWindowHandle` 跨窗口站**结构性失效**，
   在客体里枚举 GUI 窗口一定失败。要操作 GUI：
   - 读屏：`prlctl capture` 截图 + macOS Vision OCR（见第八节）；
   - 发键：`prlctl send-key-event`（见第八节）；
   - GUI-only 的功能（如 PE 安装）：用 `--test-hook` + `C:\br-test.json`（见第七节），
     不要试图点按钮。

3. **快照回滚会连 VM 配置一起还原**。`prlctl snapshot-switch` 之后，
   `Pause idle` 会变回快照里的旧值（通常是 on）。所以**每次回滚后立刻**重跑
   `prlctl set "Windows 11" --pause-idle off`。

## 一、虚拟机基本操作（prlctl 速查）

```bash
# 看状态
prlctl list -a                                  # 运行/暂停/关机
prlctl list -i "Windows 11" | grep -E "State:|Pause idle"

# 电源
prlctl resume  "Windows 11"                     # 从 paused 恢复（首选，别动不动重启）
prlctl start   "Windows 11"
prlctl stop    "Windows 11"                      # 正常关机
prlctl stop    "Windows 11" --kill               # 强制断电（断电测试用）

# 在客体里执行命令（已提权，可跑 bcdedit/diskpart/dism）
prlctl exec "Windows 11" cmd /c "echo OK"        # 回显 OK 即通道正常
prlctl exec "Windows 11" powershell -NoProfile -Command "..."

# 截屏（PNG）
prlctl capture "Windows 11" --file /tmp/shot.png
```

- **判断通道是否可用**：`prlctl exec "Windows 11" cmd /c "echo OK"` 回 `OK` 即通。
  回 `Unable to open new session...` → 看坑 1。
- **GUI 应用会卡住 `prlctl exec`**：启动 GUI 用 `cmd /c "start \"\" /b 程序.exe ..."`，
  否则 `prlctl exec` 会一直等它退出（GUI 不退）。
- WinRE 里**没有** Parallels Tools，`prlctl exec` 在 WinRE 内不可用；
  WinRE 阶段只能靠 `capture` + `send-key-event`。

## 二、快照纪律（AGENTS.md 硬性要求）

**每次改虚拟机启动项（BCD、默认项、一次性启动序列、WinRE 注册、PE 部署）之前，
必须先建并核验一个新快照；最多保留最近 2 个。**

```bash
# 建快照（命名：年月日-时分-用途）
prlctl snapshot "Windows 11" --name "20261012-0002-用途说明"

# 列快照（* 是当前）
prlctl snapshot-list "Windows 11"

# 删快照（注意：ID 要用 --id，裸 ID 不认）
prlctl snapshot-delete "Windows 11" --id "{快照GUID}"

# 回滚到某快照
prlctl snapshot-switch "Windows 11" --id "{快照GUID}"
```

规矩：
- 触发一次完整启动变更事务（prepare→进 PE）前就得有快照；进 PE 后再手动变更或返回，
  需要**另建**快照，不要复用早先的。
- 保持 ≤2 个。要新建而总数会超 2 时，先 `snapshot-delete` 最旧的。
- 清理只删确认属于本项目的测试快照，别碰用户的、系统恢复镜像、开发工具链。
- **破坏性测试（格式化目标卷）前的那个快照 = 你的回滚后路**。测完
  `snapshot-switch` 回去就能把目标卷和 BCD 一次性还原干净（回滚后记得关 pause-idle）。

## 三、把产物部署进客体

宿主仓库通过共享 `\\Mac\backupRestore` 映射到客体（即 macOS 侧
`/Users/x/code/backupRestore`）。交叉构建产物在
`target/aarch64-pc-windows-msvc/release/BackupRestore.exe`。

```bash
# 1) 宿主侧构建（macOS → Windows ARM64）
./build-win.sh                                   # 产物在 target/aarch64-pc-windows-msvc/release/
shasum -a 256 target/aarch64-pc-windows-msvc/release/BackupRestore.exe

# 2) 客体侧从共享复制并核对哈希（哈希必须一致，否则是旧档）
prlctl exec "Windows 11" powershell -NoProfile -Command "Copy-Item '\\\\Mac\\backupRestore\\target\\aarch64-pc-windows-msvc\\release\\BackupRestore.exe' 'F:\\BR\\BackupRestore.exe' -Force; (Get-FileHash 'F:\\BR\\BackupRestore.exe' -Algorithm SHA256).Hash"
```

- **程序目录不能放在承载注册 WinRE 的分区上**，也**不能放在卷根**；
  放一个子目录如 `F:\BR\`。放卷根会报 `program directory cannot be a volume root`，
  放 WinRE 宿主分区会报 `程序目录不能位于承载 Windows 恢复环境（WinRE）的分区`。
- 还原/第二系统还需要同目录放一份 `Recovery.exe`（可以就是 BackupRestore.exe 的副本）。
- 改完代码**务必重新复制并比对哈希**，否则会拿旧二进制测出假结果。

## 四、卷布局与角色（当前测试机）

| 盘符 | 用途 | 说明 |
|---|---|---|
| C: | 系统盘（有 Windows） | **不许**当备份源或还原目标；可读、可用它的 WinRE/BCD |
| E: | 大号测试目标卷（270G） | 可格式化的一次性目标 |
| F: | 工作/镜像卷（350G） | 放程序 `F:\BR\`、镜像、任务目录 |
| H: | 镜像库（192G，BRImages） | 现成测试 WIM 在此 |
| P: | 测试卷（64G） | 备用 |
| T: | 小测试卷（5G，数据卷） | 还原数据卷最快的目标；内容是 BRRE213+testdata |
| Y: | WINRE（0.8G） | 注册 WinRE 宿主，别碰 |

现成可用的测试镜像：
- `H:\BRRE-219-20261009\a230-focus\images\test.wim`（约 1.3MB 的小数据卷 WIM，还原 T:/E: 快）
- `F:\sysbackup.wim`、`F:\BRRE-217-20261008\system.wim`（系统镜像，大，跑系统还原用）
- 纯 WinPE：`C:\BackupRestorePE\media\media\sources\boot.wim`（测 PE 路径用）
