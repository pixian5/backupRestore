# 去除格式化 NTFS 硬校验（v2.5.4）

> 模型：GLM-5｜版本 **2.5.3 → 2.5.4**｜用户 2026-10-14 裁定 + 测试计划三确认点的落实。

## 1. 改动

`verify_formatted_volume`（core/operation_safety.rs）去掉「格式化后必须是 NTFS」的硬校验（用户裁定）。保留的强判据：**同分区 GUID/几何不变 + 卷序列号非空且已改变 + 根目录可读**——diskpart quick format 无论目标什么文件系统都会换序列号，这才是「格式化真的发生了」的证据；文件系统跟随脚本/目标，不做假设。同步更新单测（FAT32+新序列号=合法）与全部界面/日志文案（不再出现 NTFS 字样）。

**注意**：diskpart 脚本（`diskpart_format_script`）仍写死 `format fs=ntfs quick`——若需「格式化后保留目标原文件系统（如 exFAT）」需另行改脚本，本轮未动。
