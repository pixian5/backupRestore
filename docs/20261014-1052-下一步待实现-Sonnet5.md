### 2. UI 三入口拆分（§2.8 第 4 步）

把「单系统还原」tab 拆成 A/B/C 三个入口（**已决定不合并第二系统 tab**，最终 6 个 tab）：
- **A 还原系统到 C 盘**：目标锁定 `%SystemDrive%` 的 `volume_identity`（**绝不写字面 'C'**，见 P4）；
  界面显示实际盘符「当前系统盘 (D:)」；隐藏误导性的「源卷」控件（见 P3）；必走离线，两道确认保留。
- **B 还原数据到非 C 盘**：默认在线；把「在线不格式化（覆盖）vs 离线会 diskpart 格式化」写在界面上。
- **C 还原系统到非 C 盘**：可在线（不重启）。
- 校验矩阵不能省（交接文档 §2.4）：A 的容量预检要**加强**（用户无法换盘纠错）。
