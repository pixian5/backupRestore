## 1. 一开始就撞上「空集通过」

第一次写 T2（选中失败任务 → 详情必须显示错误码）跑出来是：

```
T2_NO_FAILED_TASK=1
T2_FAILED_DETAIL_SHOWS_CODE=0
```

`H:\brwork\tasks` 里 50 个历史任务**全都没有错误码**了。也就是说这条判据会
「因为无对象可测而恒绿/恒红」——两种都不能算验收通过。

**改法：自带夹具。** 每次跑之前建两个目录、跑完删掉（`FIXTURES_REMOVED=1` 自证）：

| 夹具 | 内容 | 用途 |
|---|---|---|
| `9999-fixture-failed` | 复制某个真任务的 `task.json` + `status.json`，改 `stage=failed`、`error`、`errorCodeText=BR-PE-039`、`updated=now` | T2：详情必须显示任务号与 `BR-PE-039` |
| `9998-fixture-badstatus` | `task.json` 正常，`status.json` 故意写成半个 JSON | T3：坏记录不能让整窗打不开、也不能让列表少项 |

夹具形状从**磁盘上已有任务**复制再改字段——`Task` 的必填字段（`created`/`bootOnce`/`status`/`bootPlan.mode`）
手写少一个就是 `missing field`（10-27 已栽两次）。

## 2. 三个新仪器坑（症状都与真因完全不像）

### 坑 1：PS 5.1 的 `Set-Content -Encoding UTF8` 会写 BOM

夹具被判成「记录损坏」，详情只有三行：

```
task.json | expected value at line 1 column 1 | H:\brwork\tasks\9999-fixture-failed
```

`serde_json` 不接受 BOM，在 **column 1** 就报错。而判据那一侧显示的是
「详情里没有任务号」——**真因被埋了两层**。

修法：写 JSON 一律 `[IO.File]::WriteAllText($path, $json, (New-Object System.Text.UTF8Encoding($false)))`。
（与本项目既有教训「读文本要 `-Encoding UTF8`」正好配对：**读怕 GBK 误判，写怕 BOM**。）

### 坑 2：`CB_SETCURSEL` **不发送** `CBN_SELCHANGE`

选中确实变了（`CB_GETCURSEL` 依次 0/1/2），但详情**纹丝不动**，长度恒为 283。
Win32 明文规定 `CB_SETCURSEL` 不发该通知——而详情面板正是靠这条通知刷新的。
看起来像「详情不显示任务号」，实际是「通知没发」。

修法：自动化里**补发等价通知**：

```
PostMessage(combo, CB_SETCURSEL, i, 0)
PostMessage(win, WM_COMMAND, MAKEWPARAM(1401, CBN_SELCHANGE=1), combo)
```

并把读取改成「轮询到详情出现本项 id 为止（最多 5×150ms）」——通知是异步的，
固定等 200 ms 偶发读到**上一项**的详情，会同时污染 id 与码两个判据。

### 坑 3：跨进程改文字必须用 `SetWindowTextW`

探测「零任务态」时先自己拼 `SendMessageW(WM_SETTEXT, ptr)`，回读长度仍是 **7**（「任务：52 个」）
——**没写进去**。于是「量尺寸」量的是旧文字，还得出了「装得下」的假结论。
改成 `SetWindowTextW` 后立刻生效，真相才出来。

> 教训统一成一句：**任何「改了再量」的探测，必须先回读确认改成功**，否则量的是旧值。

## 3. 抓到的真缺陷：零任务态标签 156 px 塞进 80 px

标签控件 `1400` 宽 **80 px**。零任务态文案是「任务：0 个（尚无任务记录）」，
用控件自己的字体实测 **156 px** → 被裁掉一半。

**为什么一直没发现**：本机 tasks 里有 50 条任务，判据只可能跑在「有任务」的状态
（标签是「任务：52 个」= 66 px，装得下）。这个分支**全新安装/清空后才会出现**——
一装就给用户看。

**修法**（`native_gui.rs`）：标签只报数字「任务：N 个」（最宽也就 66 px），
说明挪到 **696 px 的提示条**（`1407`）；零任务时提示条写「尚无任务记录：先在主窗口创建任务…」。
控件一个没动 → 几何与基线判据天然仍绿。

修复读数：`EMPTY_LABEL_CLIENT_W=80 EMPTY_LABEL_TEXT_W=60 EMPTY_LABEL_FITS=1`（修前 156 / 0）。
