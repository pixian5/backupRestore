# 任务存储库与原子持久化独立为task_store (v2.9.5)

> **时点**：2026-11-04 00:35  
> **版本**：v2.9.4 -> **v2.9.5**（改源代码升版 +0.0.1）  
> **模型**：Gemini  
> **主题**：架构演进第十阶段之核心库任务存储库与原子持久化独立为 `task_store.rs`，`backuprestore-core/src/lib.rs` 剧降至 1,673 行  

---

## 一、背景与动机

在 BackupRestore 的任务生命周期与容灾体系中，任务持久化与断电恢复机制居于绝对基石地位：
1. **原子重命名与 Flush 语义**：任务状态转换与记录更新必须具备原子性（`write_json_atomic`），在 Windows 平台上依赖底层 Win32 API（`MoveFileExW(MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)`、`CreateFileW`、`FlushFileBuffers`），确保写入边界即使发生突发断电也不会留下损坏的半包 JSON；
2. **三态事务与断电重放（`StateTransaction`）**：在阶段跃迁时先写完整状态事务，再更新主任务与状态快照视图；若中途掉电，下次启动时必须能依据事务日志容忍盘符重排、校验卷身份并完成自愈重放；
3. **任务存储生命周期管理（`TaskStore`）**：包括 `create`、`load`、`write_transition`、`write_failure`、`write_failure_coded`、`incomplete_tasks`、`cleanup` 等状态流转与历史工作树回收；
4. **强类型路径与指纹校验**：包括任务 ID 校验（UUID）、相对/绝对路径规范化判定、SHA256 计算与镜像验签、载荷完整性断言。

此前，上述逻辑以及相关的 45 行 Windows 专属 Win32 FFI、600 余行持久化实现以及 544 行密集测试代码全部混合堆积在 `crates/backuprestore-core/src/lib.rs` 内部，同时原 `state_transaction.rs`（73 行）独立在外导致实现割裂。

本轮重构将 `TaskStore`、原子 I/O、哈希与校验以及状态事务合流封装为高内聚子模块 `task_store.rs`，彻底消除 `lib.rs` 中的 Windows FFI 混杂，实现核心数据模型定义与存储引擎的彻底解耦。

---

## 二、核心改动与重构设计

### 1. 新建 `crates/backuprestore-core/src/task_store.rs`（1,237 行）

- **底层原子写入与 Windows 系统调用完全隔离**：
  - 封装跨平台 `write_json_atomic` 与 `read_json`（原生兼容 PowerShell UTF-8 BOM 头处理）；
  - Windows 专属 `atomic_replace`、`flush_file_path` 与 `kernel32` FFI 声明（`MoveFileExW` / `CreateFileW` / `FlushFileBuffers` / `CloseHandle`）完全收拢于 `task_store.rs` 内部，使 `lib.rs` 成为纯粹的跨平台领域契约库。
- **任务存储库实现（`TaskStore` 与 `CleanupReport`）**：
  - 收拢任务路径计算、任务目录初始化、状态流转事务写入、结构化错误码注入与多任务工作区清理回收；
  - 集成容灾策略 `pending_task_policy`、未完成任务枚举 `incomplete_tasks`（严格区分探针任务与真实未结任务）。
- **状态事务持久化与断电重放（`StateTransaction`）**：
  - 合并原 `state_transaction.rs` 的全部逻辑，提供事务边界提交与崩溃断电自愈重放（`commit_state_transaction` / `replay_state_transaction`），保证任务身份、目标校验与合法状态流转守卫。
- **文件指纹与路径校验工具**：
  - 收拢 `sha256_file`、`verify_sha256`、`verify_image_file`、`validate_payload_files`、`validate_task_id`、`validate_relative_path`、`validate_absolute_path`。
- **单测自治归位**：
  - 将原堆叠在 `lib.rs` 中的 20 组任务存储、原子重命名、UTF-8 BOM 解析、状态事务与断电重放单测全量迁移至 `task_store.rs` 内部。

### 2. 精简 `crates/backuprestore-core/src/lib.rs` 并删除旧文件

- 注册并导出：`pub mod task_store; pub use task_store::*;`，对外契约完全保持兼容；
- 清理 `lib.rs` 顶层 45 行 Win32 FFI 与 6 行无用标准库引用（`fs`、`io`、`sha2` 等），`lib.rs` 降至 **1,673 行**（较重构前 2,842 行单次净减 **1,169 行**，较初始 3,463 行累计瘦身 **51.7%**）；
- 删除已合流的旧文件 `crates/backuprestore-core/src/state_transaction.rs`。
