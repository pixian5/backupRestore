# 清理测试第二系统分区与 C 盘无用工具链（v2.6.64 时点，未改代码）

- 时点：2026-10-27 00:35 · 版本 **保持 2.6.64**（本轮未改源代码）
- 触发：用户指出「第二分区第二系统根本也是测试的，留着干什么」，
  并纠正我上一轮**搞错了对象**
- 结果：宿主空闲 **104 GiB → 190 GiB**（+86 GiB），C: 释放约 5.3 GiB，
  悬空启动项清零，重启验证正常

---

## 1. 先记我上一轮做错的两件事

| 我做错的 | 正确 |
|---|---|
| 把「测试盘」理解成 `T:`（5 GB 数据卷），把**卷**删了 | 用户说的是**第二系统那个分区**（`F:`，350 GB） |
| 顺手把刚生成的**测试镜像** `brtest-000423.wim` 也删了 | **镜像 ≠ 分区**。镜像该用时留着，不该用时才删 |

用户的原话：「测试盘跟测试镜像是一样的东西吗？分区跟镜像你都搞不明白吗？」
——**分区是容器，镜像是文件**，清理时不能混为一谈。已写进长期约定。

## 2. 定位第二系统（先确认，再动手）

```
disk0 p4  letter=C  249.47G  hasWindows=True   ← 当前运行系统
disk1 p2  letter=H  191.98G  hasWindows=False  ← 工作盘（部署位 H:\brwork）
disk2 p2  letter=F  349.98G  hasWindows=True   ← 测试第二系统 ← 要删它
```

`bcdedit /enum {current}` → `device partition=C:`，默认项 `{current}` 指向 C:。
**F: 上还有 `br-target` / `BackupRestoreBuild` / `BuildTools` 等目录**，先确认
构建不依赖它们：`build-windows.ps1` 的 `CargoTargetDir` 默认走
`$env:CARGO_TARGET_DIR` 或 `repoRoot\target`，我们每次显式传 `H:\br-target`，
部署位恒定 `H:\brwork`；脚本注释还写明「F: 是镜像卷，旧工作区 F:\BR 已退役」。

## 3. 执行

### ① 文件级 BCD 备份（改引导前的规矩，不拍整机快照）

`bcdedit /export H:\brwork\BCD-backup-before-delete-secondary.bcd` → **503,808 字节**
（判据是文件非空 + 可枚举，不是字节数；10-15 曾记过 651,264）。

### ② 删第二系统分区

`diskpart` → `select disk 2` → `select partition 2` → `delete partition`
→ **`F_GONE`**，disk2 已分配从 350 G 降到 0.02 G（只剩 MSR）。

### ③ 清启动项（★ 这里踩了一个坑）

先手删 4 个描述为 `UEFI BR217-secondary` 的项，以为只有 4 个。

```
删前 104 处 → 删后 100 处   ← 说明实际有 100+ 个，不是 4 个
```

**坑在哪**：`bcdedit /enum` 在中文系统上把 `identifier` 输出成「**标识符**」，
被我的 ASCII 通道过滤吃掉了，所以按 `identifier` 匹配不到，只剩纯 `{GUID}` 行。
（同类坑 10-26 在 PS 的 GBK 解码上栽过一次：过滤会悄悄改变你看到的数据。）

改法：**在 mac 侧用 awk 按「纯 GUID 行 + 紧随的 description 行」配对解析**，
把 GUID 列表写成文件喂给 VM 里的 PowerShell 循环删除。

```
FOUND=103   ATTEMPTED=103   REMAINING=0
```

### ④ 回收虚拟磁盘（这一步才是真正还给宿主空间）

删分区只清了 VM 内部，**宿主空间没变**。真正的占用在虚拟磁盘文件：

```
du -sh harddisk2.hdd  →  85G
```

无快照（有快照时 compact 无效）→ 停机 → `prl_disk_tool compact --hdd …` →

```
85G → 4.0M      宿主空闲 104GiB → 190GiB
```

**保留了磁盘本身**（只回收空间），以后想再建测试系统可以直接用。

### ⑤ C 盘无用工具链

| 目录 | 大小 | 处理 |
|---|---|---|
| `C:\br-target` | 0.1 G | 删 |
| `C:\BackupRestoreBuild` | 1.6 G | 删 |
| `C:\BuildTools` | 3.9 G | 先搬 `H:\_archive`，验证后删 |
| `C:\BackupRestoreBCD` / `WinRE-PoC` / `diag` / `0` / `Proram Files` / `BackupRestore-logs` | 小 | 删 |

**保留**：`C:\Mac`（Mode `d-r---`，是 Parallels 共享挂载点，不是残留）。

### ★ 用「删前跑一次 + 删后再跑一次」证明没删错

不是靠"我觉得没用"，而是让构建自己说话：

```
删前：DEPLOYED SHA256=c4697e00…
删后：DEPLOYED SHA256=c4697e00…   ← 完全一致
```

两次哈希相同，证明那批目录**确实没被依赖**。
`BuildTools` 3.9 G 先搬到 `H:\_archive` 再删，是为留一条可回滚的路。

### ⑥ 重启验证

`bcdedit /enum` → `default={current}`（C:）、`displayorder` 只剩一项、
ESP 指向 `S:`、无 BR217 残留 → 重启 → 卷齐全（H/C/Y/S）、部署 SHA `C4697E00` 完好。

## 5. 写进长期约定的两条

1. **测试盘/测试卷用后即删**（别只清数据留着卷）：删前用 `Get-Partition -DriveLetter X`
   确认 disk/part 号，删完列同盘其余分区复核没误伤。
2. **分区 ≠ 镜像**：镜像按用途保留，不该用时才删；清理前先分清要删的是容器还是文件。

## 6. 遗留

- `dist/` 历史包未清（不入库，此前结论是「动它反而有伪造历史的风险」，维持）。
- 第二系统**磁盘保留**（已回收空间），若确定永远不再建测试系统，可再移除设备
  彻底删掉 `.hdd`——当前收益已拿到（85 G），故未继续。
- 离线 RE 还原分支仍未实机跑（宿主此前不足 220 GiB；现在 190 GiB 仍偏紧，
  建议腾到 220 GiB 以上再做）。
