## 3. 可复用经验（本轮新发现）

1. **★ `df` 必须读 Data 卷**：macOS 上 `df /` 显示的是只读快照卷（disk3s1s1），其 Used 列是
   快照增量——本轮它显示「13Gi used / 7.6Gi avail / 63%」自相矛盾，真实空闲在
   `/System/Volumes/Data`（disk3s5）：**7.6 GiB / 100% 容量**。差点因误读低估危险度。
2. **★ 空卷的虚拟磁盘文件不会自动缩小**：F: 格式化为空卷后，宿主侧 harddisk2.hdd 仍占 126G，
   **停 VM 即收缩**（本轮未跑 compact 就回收了）。显式 compact 的正确语法是
   `prl_disk_tool compact --hdd <path>`（**不是 `--disk`**，用错只打印帮助、不执行）。
3. **`prlctl exec` 删本地文件用单写反斜杠**：`del /q H:\BRImages\x.wim` 单写成功；
   双写报「指定的路径无效」（del 场景）。注意 rmdir 双写反而成功——**以单写为准**，
   与 MEMORY 里「UNC 双写」规则不矛盾（那条管 UNC）。
4. **镜像保留策略**：留「最新血脉镜像 + PE 载荷 + 冒烟素材」，旧镜像被实测取代即可删。
   血脉判定法：查最近一次 A 入口回归文档里用的哪份 wim（本轮 = br-2629-20261023.wim）。
