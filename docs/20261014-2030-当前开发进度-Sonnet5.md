## 关键事实（与交接文档不同，以本轮证据为准）

- **BCD default 从未被留在半成品 F: 系统上**。日志里 `/set {bootmgr} default {12e3701c…}`
  返回「操作成功完成」，失败前的校验回读与当前实时 BCD 都显示 default = 主系统 C:。
- **失败的唯一失配项是 `resumeobject`**：快照里没有该字段（`previous=None`），
  BCDBoot 为新 F: 系统新增了 `{66375ee0…}`（与新 loader `{66375ee1…}` 是兄弟 GUID），
  代码既不删除、校验又把 `(Some, None)` 判为失配。
- **该失败是确定性的**：条件不随时间变化，`resume` 重试必然在同一处同样失败。
  这就是阶段 3 两次过不去的原因。
- **`BootRepaired` 不可 `abandon-task`**（不在 `can_abandon_before_target_write`），
  只能 `resume`。交接文档「abandon-task 或继续」这句不准确。
- `assert_boot_default_preserved` **本来就会自愈**（回读→回写→再回读），不要按文档去「修」它。
