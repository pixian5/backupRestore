## 二、改动清单（native_gui.rs）

### 1. C 页移除源卷栏（3 处 + 文案）

- `set_operation_visibility`：`show_source = operation == "backup"`（原 `matches!(operation, "backup" | "create-secondary")`）。
- `layout_operation`：`source_visible = layout_op == "backup"`。
- `drive_role_description`：删除 `(source, "create-secondary")` 中英两个分支（行已隐藏，详情框不显示）。
- 布局连带：`source_visible=false` 时目标行上移到 y=100（原 C 页目标行在 256），C 页整链 -156px（详见下表）。

### 2. C 页目标卷排除当前系统（索引换算是重点）

**教训：`selected_drive_letter`/`select_drive` 一直假设 combo 索引 ≡ `state.drives` 索引**（`set_drive_items` 全量填充使该假设恒成立）。直接删 combo 项会让索引错位——「选了 E: 实际写到 F:」比不过滤更危险。因此新增：

```rust
/// C 入口目标卷枚举视图：排除当前系统盘。None = 不过滤（恒等映射）。
unsafe fn target_combo_indices(state: &State) -> Option<Vec<usize>>;
/// 盘符 → target combo 项索引（经过滤视图换算）。
fn drive_combo_position(view: Option<&[usize]>, state: &State, letter: &str) -> Option<usize>;
/// 目标 combo 在当前入口下的期望项数（与填充结果对称，空视图=1 个占位项）。
unsafe fn target_combo_expected_count(state: &State) -> usize;
```

四个换算点全部收口：
1. `set_drive_items`：target combo 按视图填充；desired 选中位经 `drive_combo_position` 换算；视图空时填占位项「没有可选目标卷（已排除当前系统盘）」。
2. `selected_drive_letter`：读 target combo 时经视图反查 drives 索引。
3. `select_drive`：写 target combo 时换算；**视图里找不到就保持不动，绝不可回退全量索引**（那会选中错误分区）。
4. 测试钩子 `--test-drive-json` 的 `target_volume` 注入同步换算。

**第一轮实机验收暴露的第二个坑**：combo 内容只在 `set_drive_items` 填充时定死，**tab 切换不重填**——首轮验收实测 C 页下拉仍含系统盘（启动时按 backup 填了全量）。修复：`update_operation` 里按「当前入口期望项数 vs `CB_GETCOUNT` 实际项数」校验，不符即带选中重填；离开 C 回 A/备份/PE 时同样恢复全量（A 页必须能选系统盘）。gui.log 实测 `target combo refilled: op=create-secondary keep=D`，从 PE→C 保留原选中 D:。

## 五、本轮新踩的坑（记入手册防再犯）

1. **combo 索引 ≡ drives 索引是隐性契约**：任何按入口过滤下拉项的改动，必须同步 `selected_drive_letter`/`select_drive`/desired 定位/测试钩子四处换算，否则索引错位到别的卷。
2. **tab 切换不重填 combo**：下拉内容只在 `set_drive_items`（启动/刷环境/切语言）时定死；切入口要变枚举必须显式重填。
3. `Add-Type` 的 C# 里 `SendMessage` 传 `StringBuilder` buffer 需要**单独声明 StringBuilder 重载**（`l: IntPtr` 版编译不过；CB_GETLBTEXT 专用）。
4. windows-rs `SendMessageW` 对 `CB_SETCURSEL` 的 wparam 要 `usize`（`as isize` 编译失败）；安全 fn 调用 unsafe 的 `selected_operation` 必须把 helper 声明为 `unsafe fn`。
