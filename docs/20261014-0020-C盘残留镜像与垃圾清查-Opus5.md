## 5. 扫描方法备忘（下次直接用）

- 全盘 `Get-ChildItem 'C:\' -Recurse -Force -Include …` 会**因单个目录拒绝访问而整体中止**，
  即使加了 `-ErrorAction SilentlyContinue`。改用**分目录 `cmd dir /s /b`** 才扫得全。
- 体积统计用 `Get-ChildItem <dir> -Recurse -Force | Measure-Object -Property Length -Sum`；
  单个大文件用 `Get-Item -LiteralPath`（`-LiteralPath` 避免路径含特殊字符）。
- 盘符容量用 `Get-CimInstance Win32_LogicalDisk | Where-Object { $_.DeviceID -eq 'C:' }`
  （`-Filter` 里的引号经多层 shell 传递会变成 `无效查询`）。
