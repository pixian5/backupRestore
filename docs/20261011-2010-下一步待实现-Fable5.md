## 一、2.2.6 / 2.2.7 可靠性三项的客体复验（最高优先）

代码已实现并通过本机测试，但**真实客体上都还没回读过**。

1. **`{bootmgr}.resumeobject` 恢复回读**
   - 验证点：准备任务 → 快照 BCD → 执行 → 清理后，`{bootmgr}` 的 `resumeobject`
     与基线逐字段一致（大小写不敏感比对）。
   - 注意：`bcdedit` 在 SYSTEM 通道下输出**中文本地化字段名**（「标识符」），
     断言必须只认 GUID / 值，不能认字段名。
2. **孤儿 resume 对象清理**
   - 验证点：清理只删「loader 已不在 live BCD 中」且「GUID 未被任何 live
     `resumeobject` 引用」的对象；人为造一个仍被引用的对象，确认不被误删。
3. **`FlushFileBuffers` 防撕裂**
   - 验证点：在终态文件写入后立刻真实断电，重启回读 `status.json` 不出现截断/撕裂。
   - 2.2.6 的实现因句柄只开 `GENERIC_READ` 实际未生效（os error 5），
     2.2.7 改为 `GENERIC_READ | GENERIC_WRITE` 后**尚未真机复测**。
