## 一、背景与动机

在 BackupRestore 的引导链武装与 PE 还原恢复体系中，对 Windows BCD（Boot Configuration Data，启动配置数据）条目的解析与 GUID 校验是至关重要的安全防线：
1. **UTF-16LE / UTF-8 混合编解码（`decode_bcdedit_bytes`）**：Windows 11 的 `bcdedit.exe` 在重定向管道输出时，依据不同系统区域及控制台代码页可能输出带有或不带 BOM 的 UTF-16LE 字节流或 UTF-8 流。错误的解码会导致全角中文字符错乱或误将启动项判定为空；
2. **结构化条目与加载器甄别（`BcdLoader` / `pick_windows_loader`）**：从 `bcdedit /enum all /v` 的长篇输出中，准确解析 Windows Boot Manager（启动管理器）与 Windows Boot Loader（启动加载器），提取 `displayorder` 菜单顺序与 `default` 默认项；特别是在恢复环境 PE 内，必须严格识别出真正的 Windows 启动项，同时坚决过滤排除包含 `winpe Yes` 的 PE 引导项，避免发生重启再次循环跌回 PE 的引导灾难；
3. **GUID 与知名别名严格守门人（`require_guid` / `require_identifier`）**：`bcdedit` 在标识符参数为空或缺失时，会极其隐蔽地静默作用于当前默认项 `{default}`。历史上曾发生过空 GUID 误将用户正常系统启动项篡改成 ramdisk 载荷的严重事故。因此，守门人逻辑必须对空串、畸形 GUID 坚决拦截，且只允许白名单中的知名别名（`{bootmgr}`）放行，绝不允许 `{default}`/`{current}` 混入；
4. **Ramdisk 与 SDI 设备规格化（`ramdisk_spec` / `ramdisk_device_options_guid`）**：严格闭合方括号形态（`ramdisk=[F:]\path,{guid}`），确保 `]` 紧随盘符闭合，杜绝历史踩坑过的 `[path],{guid}` 或 `[path,{guid}` 导致 bcdedit 报“指定的设备无效”的隐患。

此前，上述逻辑及 20 组严苛的单测全部交织在 `crates/backuprestore-cli/src/text_parsing.rs` 中。本轮重构将 BCD 解析、加载器甄别、GUID 守卫及 Ramdisk 设备路径规格化完全抽离独立为 `bcd_parse.rs`。

## 二、核心改动与重构设计

### 1. 新建 `crates/backuprestore-cli/src/bcd_parse.rs`（635 行）

- **BCD 编码与基础解析**：
  - `looks_like_utf16le`、`utf16le_to_string`、`decode_bcdedit_bytes`；
  - `bcd_field_name_is`（双语多字段匹配）、`bcd_output_has_bootsequence`；
  - `braced_token`、`identifier_of`、`partition_letter`。
- **条目结构化提取与选择**：
  - `BcdLoader` 数据结构；
  - `bcd_loader_entries`、`bcd_display_order`、`bcd_boot_manager_default`；
  - `pick_windows_loader`（按菜单顺序与物理文件存在性甄别真正 Windows 加载器）。
- **GUID 与知名别名守门校验**：
  - `first_braced_guid`、`parse_guid`、`is_guid`；
  - `require_guid`（硬约束防御，空 GUID 坚决报错，拒绝触碰 `{default}`）；
  - `is_well_known_identifier`、`require_identifier`（白名单放行 `{bootmgr}`，严拒 `{default}` 等别名）。
- **Ramdisk 与 SDI 设备串构建**：
  - `ramdisk_spec`、`split_volume_and_path`；
  - `ramdisk_device_options_guid`（仅从 `device`/`osdevice` 提取设备选项对象 GUID）；
  - `staging_sdi_path`（强制反斜杠绝对路径）。
- **单测自治归位**：
  - 迁入 20 组完整 BCD 单元测试（UTF-16LE 解码、BOM 兼容、GUID 格式、空 GUID 拦截、知名别名白名单与黑名单拒绝、Ramdisk 方括号位置校验、两套历史畸形形态防御、双语及多加载器选择优先级等）。

### 2. 精简 `crates/backuprestore-cli/src/text_parsing.rs`

- 顶层重导出：`pub(crate) use crate::bcd_parse::*;`，实现全仓零修改平滑过渡；
- 在 `crates/backuprestore-cli/src/main.rs` 注册 `mod bcd_parse;`；
- 移除 240+ 行生产代码与 440+ 行单元测试代码；
- `crates/backuprestore-cli/src/text_parsing.rs` 行数由 2,810 行下降至 **2,121 行**（单次净减 689 行，较初始 3,477 行累计降幅达 **39.0%**）。
