## 六、操作纪律速查（本机 + 虚拟机，接手必读）

1. **prlctl**：`/usr/local/bin/prlctl` 是坏包装器；必须先
   `export PATH="/tmp/prlbin:$PATH"`（→ `/Applications/Parallels Desktop.app/Contents/MacOS/prlctl`）。
   **`/tmp/prlbin` 会被 macOS tmp 清理（本轮已被清过一次）——每会话开始先 `ls /tmp/prlbin`，没有就
   `mkdir -p /tmp/prlbin && ln -sf ... /tmp/prlbin/prlctl`**。
2. **虚拟机双通道**：prepare/bcdedit/读卷身份必须走 **SYSTEM 通道**（`prlctl exec "Windows 11"`，
   默认 nt authority\system）；交互会话（`--current-user`）未提权，读卷报 error 5。
3. **prlctl exec 返回 137/SIGTERM 是常态**；输出文件常晚 5–10 秒落盘，读前先 sleep。
4. **投进虚拟机的 `.cmd` 一律纯 ASCII**——本轮又踩一次（脚本里写了中文 findstr 模式，
   整个脚本不执行）。匹配中文日志用英文子串。
5. **zsh 双引号里 UNC 写四个反斜杠**（`\\\\Mac\\backupRestore\\...`）。
6. **本机 `grep 'a\|b'` 交替不可靠**——用 `grep -E`。
7. **PowerShell `Out-File -Encoding utf8` 在虚拟机上产出 UTF-16**——宿主侧用
   `iconv -f UTF-16LE -t UTF-8` 读；cmd 重定向产出 GBK——用 `iconv -f GBK`。
8. `del` 失败仍返回 0 的陷阱（见 §2.2-3）；挂载镜像内删系统文件要 takeown+icacls。
9. 破坏性操作前：`bcdedit /export` 到共享盘（SYSTEM 通道可直接导出，在线态可行）。
