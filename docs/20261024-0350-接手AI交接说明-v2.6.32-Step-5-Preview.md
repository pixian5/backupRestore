## 1. 这个项目是干什么的（一段话）

Windows 下的整机备份/还原工具（Rust 工作区，界面 = 原生 Win32）。三条还原入口
（A 还原系统到 C: / B 数据到非 C: / C 系统到非 C:）+ 备份。两条应用镜像通道：
**格式化还原走 DISM**；**`--skip-format` 且目标已含 Windows 时走 wimlib 覆盖式通道**
（v2.6.27 起不带 `--no-acls`，镜像目录的属主/访问控制列表完整还原）。
判据只认目标卷上 `Windows\System32\config\SYSTEM` 是否存在（`pe_safety::target_is_windows_volume`）。

## 8. 环境坑（近 24 小时新增/复犯的）

- **从 macOS 写进虚拟机的 `.cmd` 必须 ASCII + CRLF**：LF 会让 cmd 把多行拼成一行，
  报错是「`ey` 不是内部或外部命令」这种半截单词，且**第一行都不执行**。
  修法：`open(p,'wb').write(s.replace('\n','\r\n').encode('ascii'))`。
- `.cmd` 里 PowerShell 的 `-Pattern` **别用中文**（GBK 解析成乱码 → 零匹配）；
  查中文日志用 ASCII 关键词（`BCD`、`wimlib`）。计数/比对别用 `| find`（报「参数格式不正确」），
  用 PowerShell 的 `-match` 全量文本比对。
- **新写的纯函数要放跨平台模块**（如 `failure_policy.rs`），别放 `native_gui.rs`——
  后者 `#[cfg(windows)]`，macOS 单测 collected 不到，测试等于白写（本轮先踩）。
- **改完 `Cargo.toml` 版本号要跑一次 `cargo check` 刷 `Cargo.lock`**，否则虚拟机内
  `--locked` 构建直接失败（`cannot update the lock file`）。
- 部署前必须以 **SYSTEM 通道**杀掉自启图形界面（`--current-user` 的 `taskkill` 拒绝访问），
  否则 `Copy-Item` 失败、`DEPLOY_EXIT=1`。
- 图形界面驱动链路：`tools/win-clicker/br-s1.sh <脚本.ps1>` 在交互桌面以 High IL 跑 PS；
  控件 ID = 1003 创建任务 / 1202 源卷 / 1204 目标卷 / 1214 格式化勾选框。
- `prlctl exec` 返回 137 是常态；输出文件常晚 5–10 秒落盘；瞬时
  `PrlJob_GetResult: Invalid argument` 直接重试。
