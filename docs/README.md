## 这里放什么

`docs/` 是**过程文档**：每轮开发做了什么、为什么这么做、当时量到什么数字。共 341 份顶层 md。

它**不是**权威结论的来源。写于不同时间、不同模型之手，多份互相矛盾或已被实机推翻——
读它要带时点，判读规则见 [`文档索引.md`](../文档索引.md) 的「三条判读规则」。

## 命名规范

`docs/` 下除本文件外，文件名统一 `YYYYMMDD-HHMM-<标题>[-<模型名>].md`。
完整规则（含无日期文件的兜底办法、用户指定名称的例外）见 [`文档索引.md`](../文档索引.md) 顶部的「命名规范」。
