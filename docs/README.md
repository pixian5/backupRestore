1. **版本号是标签，不是文档 ID。** 2.2.2 就同时挂在 `20261010-1910`（数据卷，跳过 `BCDBoot`）和 `20261010-2200`（系统卷，通过 `BCDBoot`）上。判定覆盖范围须列全该版本下所有文档。

3. **统计数字必须带时点和口径**（HEAD commit / 截止时刻 / 是否含本索引）。
