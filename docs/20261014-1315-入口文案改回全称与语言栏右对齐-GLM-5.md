# 入口文案改回全称与语言栏右对齐（v2.5.1）

> 模型：GLM-5｜版本 **2.5.0 → 2.5.1**｜用户两条规定：①三个入口名称必须用拍板原文案，②语言栏靠右显示。

## 1. 改了什么

### ① 入口名恢复全称（2.5.0 曾擅自简称化，用户纠正）

三个入口的正式名称恢复为用户拍板原文案，**此后不得再改**：

| 内部键 | 正式名称（全称） |
| --- | --- |
| `restore-existing`（A） | **还原系统到 C 盘** |
| `restore-data`（B） | **还原数据到非 C 盘** |
| `restore-system-other`（C） | **还原系统到非 C 盘** |

涉及位置（`native_gui.rs` 全部改齐）：tab 按钮文字（`ui_text` 的 restore/restore_a/b/c）、确认框与摘要显示名（`operation_display`）、tooltip 开头（`tooltip_text`）、状态栏长提示（`*_hint`）、两处目标闸门的指引文案、12 处代码注释。2.5.0 用的「系统还原C盘/数据卷还原/他盘系统还原」全部清除。

### ② 语言栏靠右显示

- 语言标签 + combo 在 `layout_operation` 里按实际客户宽**动态右对齐**（combo 宽 180，右缘 = 客户宽 − 20），覆盖最大化/还原/拖拽任意窗口状态；创建时的静态坐标按最小宽 1020 给初值。
- 顺带修复了 2.5.0 的一个隐性重叠：旧布局 tab 末缘 704 与语言标签（x=690 起）重叠 14px。

### ③ tab 行重排（为全称腾宽度）

- 「操作模式」标签收窄 130→62px；tab 起点左移 180→90。
- 按钮不等宽（全名长短不一）：备份 56 / A·B·C 各 120 / 新增第二系统 100 / 安装 PE 72，间距 3px，末缘 693；与右对齐后的语言区（最小窗宽 1020 时左缘 ~759）无重叠。

## 3. 本轮新踩的通道坑（记录备用）

- **prlctl exec 对长 -EncodedCommand 会整体超时**（连重试 3 次都挂），短命令正常——长脚本一律先经共享盘 `copy /y \\Mac\backupRestore\... C:\Users\Public\...` 复制进客体再 `-File` 执行。
- **SYSTEM 会话（prlctl exec 默认）枚举不到 Session 1 的顶层窗口**（EnumWindows 返回 0、MainWindowHandle=0）：用计划任务 `New-ScheduledTaskPrincipal -UserId 'x' -LogonType Interactive` 在用户会话跑探针，输出 Start-Transcript 落盘后经 prlctl 读回。本轮 `_tabrects3-probe.ps1` 模式（临时，用完已删，套路记在此处）。
- **TCP agent 启动失败报「系统找不到指定的文件」**时共享盘本身可能是好的（SYSTEM 侧 copy 成功）——agent 的启动链路另有依赖，本轮没深挖，直接走了计划任务通道。
- **prlctl capture** 可直接截全屏（2508×1908 是 2x retina，缩到 1254×954 与窗口坐标一致），不依赖 TCP agent。
