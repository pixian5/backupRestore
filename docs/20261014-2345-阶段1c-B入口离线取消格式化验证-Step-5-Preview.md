## 1. 阶段 1c 目标

验证 **B 入口（还原数据到非 C 盘）离线通道取消格式化**：`formatTarget=false` 是否真的让 RE 跳过
`diskpart`，改为**覆盖式应用**（保留目标卷上镜像里没有的文件）。

链路（源码核实，已实现，缺实机）：

```
GUI 复选框 ID_FORMAT_TARGET 取消勾选
  → native_gui.rs:5787  三个还原入口(restore-existing|restore-data|restore-system-other)时 push "--skip-format"
  → windows_prepare.rs:485  "--skip-format" => format_target = false
  → windows_prepare.rs:828  写入 task.target.formatTarget
  → RE 内 main.rs:2609      if target.format_target { format_target_partition(...) }   ← 跳过即覆盖式
```

## 2. 方法与判据设计

**核心判据 = 哨兵文件**（比序列号更直观）：在目标卷放一个**镜像里没有**的文件，
取消格式化 → 覆盖式应用 → **哨兵必须存活**；若仍格式化 → 哨兵必消失。

| 判据 | 期望（取消格式化） | 若格式化 |
| --- | --- | --- |
| 哨兵 `T:\SENTINEL-skipformat.txt` | **存活** | 消失 |
| 卷序列号 | **不变** `30D1A4CA` | 变（02:12 实测曾 `BC9662F5→942AF677`） |
| 非镜像文件（`Windows` / `Users` / `BuildTools`） | **保留** | 消失 |
| RE 日志 | **无** `diskpart` / `Formatting` / `erased` 行 | 有 |
