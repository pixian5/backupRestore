# 底层卷与物理设备探测模块 volume_device 独立 (v2.8.6)

> 时点：2026-11-03 22:00  
> 模型：Gemini  
> 变更性质：改源代码升版 +0.0.1（2.8.5 -> 2.8.6）  
> 核心任务：解耦巨石子模块 `windows_prepare.rs`，将 Win32 硬件底层 FFI 声明与物理卷/设备探测逻辑抽离为独立自治模块 `volume_device.rs`。

---

## 一、背景与设计考量

在巨石主入口 `main.rs` 成功瘦身突破 90%（收敛至 617 行）之后，演进计划的重心转向另一个巨石子模块——`windows_prepare.rs`。
在重构前，`windows_prepare.rs` 承担了极其庞杂的职责：
1. **任务规划与验证**：预检各卷空间、验证任务参数、编排离线恢复流程；
2. **BCD 启动项与 WinRE 注册**：创建临时启动项、管理恢复引导链；
3. **PE 镜像解压与安全注入**：解压引导文件、注入驱动、放置配置；
4. **Win32 底层设备与卷身份探测**：直接声明了大量的 Win32 底层系统 API（`CreateFileW`, `DeviceIoControl`, `GetVolumeInformationW`, `GetDiskFreeSpaceExW`, `FlushFileBuffers` 等），并且混杂了底层设备控制码（`FSCTL_LOCK_VOLUME`, `FSCTL_DISMOUNT_VOLUME`, `IOCTL_DISK_GET_PARTITION_INFO_EX` 等）的字节切片解码、物理卷身份计算、NTFS/FAT 卷刷新等裸逻辑。

这种抽象层级的混杂，使准备业务代码过度依赖底层裸 FFI 逻辑。通过将 Win32 硬件设备探测与物理卷身份解析彻底收拢至自治模块 `volume_device.rs`，不仅使 `windows_prepare.rs` 职责纯化，也使物理卷与底层设备探测逻辑具备了高内聚的复用能力。

---

## 二、变更明细

### 1. 新建 `crates/backuprestore-cli/src/volume_device.rs`（499 行）
完整收拢 Win32 底层 FFI 接口声明与物理卷/设备探测功能：
- **Win32 外部系统 API 集中声明**：
  - `CreateFileW`, `DeviceIoControl`, `CloseHandle`；
  - `GetVolumeInformationW`, `GetDiskFreeSpaceExW`, `FlushFileBuffers`；
  - `GetLastError`, `FormatMessageW`, `LocalFree`。
- **设备控制码与结构体定义**：
  - `FSCTL_LOCK_VOLUME`, `FSCTL_UNLOCK_VOLUME`, `FSCTL_DISMOUNT_VOLUME`；
  - `IOCTL_DISK_GET_PARTITION_INFO_EX` 及 `PARTITION_INFORMATION_EX` 字节切片解码。
- **核心探测与操作公共函数**：
  - `volume_identity(device_path)`：通过直接打开卷设备句柄读取物理磁盘与分区几何信息，计算稳定的卷身份标识；
  - `volume_identity_at_path(path)`：根据任意文件系统路径探测所在卷的物理身份；
  - `active_system_volume_identity()`：解析当前活动操作系统所在的卷身份；
  - `physical_volume_identity(volume_path)`：物理卷身份识别核心实现；
  - `disk_free_space(path)`：Win32 原生磁盘容量与空闲字节探测；
  - `partition_of_device_path(device_path)`：底层分区号探测；
  - `flush_volume(volume_path)`：底层强制刷写磁盘与文件系统缓冲区。

### 2. 重构 `windows_prepare.rs`
- 引入 `pub(crate) use crate::volume_device::*;`；
- 移除顶部 60 行裸 `extern "system"` API 声明及冗余的控制码常量定义；
- 移除内部实现的 `volume_identity_at_path`、`active_system_volume_identity`、`physical_volume_identity`、`disk_free_space`、`partition_of_device_path`、`flush_volume`、`volume_identity` 等函数；
- 清理未使用的 `std::ffi::c_void` 与 `std::ptr::null_mut` 导入；
- 代码行数由 3,647 行大幅降至 **3,143 行**，单次净减 504 行，较历史峰值 4,478 行累计净减 1,335 行，**瘦身幅度达 29.8%**。

### 3. 主入口注册与门禁保持
- 在 `main.rs` 中注册 `pub(crate) mod volume_device;`；
- 保留 `windows_prepare.rs` 中的 `MountLease` 与 `ensure_volume_mounted_leased` 契约，严格维持 `tools/test/source-guard.sh` 门禁规则。
