## #38 A/B 入口 + 备份 + PE 安装在当前二进制全链复跑（**需用户拍板**）

- **现状**：三者的全链实机在 v2.6.16/v2.6.20；v2.6.21 上只跑过 C 入口全链（79445787 + 771b3ee2）。此后改动集中在 C 入口 BCD 判据（`e05374d` role=NewWindows）与 RE 控制台/前台（C 入口 RE 跑已覆盖同一 `recovery_progress` 代码路径），**未触碰备份捕获 / 数据覆盖 / PE 安装逻辑**——理论低风险，严格口径未闭环。
- **怎么做**：合并一次专场：① 拍快照 → ② 备份（系统+数据两路，产出 WIM 并 `/Get-WimInfo` 验索引名）→ ③ B 入口在线数据还原到空数据卷（哨兵+序列号判据）→ ④ A 入口还原到 C:（纯净 GUI 三道确认 + 三件套）→ ⑤ 安装 PE 双模式（RAM+硬盘，截图）→ ⑥ 删快照。每步采集 EventID 1000 / WerFault。
- **成本**：半天到一天。**用户拍板点**：是否值得为严格口径投入；目标卷选择（F: 可牺牲）。
- **注意**：若门禁修复（v2.6.22）先落地，本项的 prepare 会多 2–3 分钟挂载探测——属预期，不要误判为卡死。
