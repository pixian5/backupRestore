## 4. 过程中发现并修复的问题（工具/方法层，非产品缺陷）

1. **TaskStore root 语义再确认**：`task_dir = root.join("tasks").join(id)`——root 必须是**工作区根 `H:\brwork`**；传 `H:\brwork\tasks` 会拼成 `...\tasks\tasks\...` 不存在 → `os error 3` 且裸 io 错误不带路径（resume/status/recover 同坑）
2. **PowerShell 5.1 `$list.Add (...)` 带空格调用解析失败**（UnexpectedToken，每个带空格/字符串实参的 `.Add` 全报错，不报空格的 `.Add('x')` 正常）→ 取证脚本统一改字符串插值 + `Out-File -Append`
3. **Windows 错误报告 provider 查询返回 `$null` 时 `@($null).Count=1` 假阳性**（曾误报 WER_TODAY=1）→ 判据必须先判 `-is [EventLogRecord]`/类型再计数
4. **常驻 TCP agent 是旧版**（不支持 `exec` op，报「参数错误」）→ 只读取证改走 `prlctl exec`（SYSTEM）通道：脚本 copy 到虚拟机本地盘再 `-File`，GBK 输出过 `iconv` 或直接 `Out-File -Encoding UTF8` 写共享目录
5. `dir /b ... | head` 管道提前关导致误判「载荷目录为空」→ `dir /a` 全量复证（见 ⑤）
