源码依据（`native_gui.rs:859`）：**"系统分区必须在离线环境备份；数据卷可在当前系统在线直接备份。"**

离线通道（建 BCD 一次性启动 → 进 RE → DISM 捕获）。这也是为什么这次 15 秒内就完成且 `{bootmgr}` 无变化。

## 3. 界面自动化受阻的完整过程（含 4 个坑，下次直接抄）

| # | 现象 | 原因 / 处置 |
|---|---|---|
| 1 | 脚本报"找不到类型 [Native]" | `Add-Type` 编译要用 `%TEMP%`；会话继承了 SYSTEM 的 `C:\Windows\TEMP`，交互用户不可写。**脚本开头把 `$env:TEMP/$env:TMP` 指到 `C:\Users\Public`** |
| 2 | `SendMessageI` 报"找不到入口点" | `DllImport` 默认用方法名当入口点。必须写 **`EntryPoint="SendMessageW"`** |
| 3 | 点「刷新环境」后卷列表仍为空（消息方式 `BM_CLICK` 无效） | 本条未完全定位；但**真实鼠标点击有效**（GUI 日志出现 `refresh environment; eligible_volumes=5`）。消息点击对该自绘按钮不触发 |
| 4 | ComboBox 项数读回 0（`CB_GETCOUNT`）、1203/1302 控件不存在 | 全 ID 扫描（1000–1450、2000–2100）确认**所有 combo 均 0 项**，与程序内部 `eligible_volumes=5` 矛盾 → v2.4.7 的卷列表控件拿不到项，**消息级 UI 自动化路线终止** |
