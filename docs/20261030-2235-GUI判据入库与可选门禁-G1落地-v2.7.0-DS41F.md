## 3. 三条设计原则（都是踩过的坑）

### 3.1 输出必须带 `__END__`，否则记 SKIP 而不是绿

`prlctl exec` 有约 1/8 概率不执行命令，输出为空。**空输出既可能是「没发现问题」也可能是「没跑」**。
所以 `run.sh` 只认带 `__END__` 的输出；重试 3 次仍没有 → 记 `SKIP`，退出码 **2**（不是 0 也不是 1）。

★ 为什么必须三态：「读不到」和「判据不满足」分开报，是 `经验/05` 里最贵的一条。
记成绿是假通过；记成红会训练人忽略红判据。

### 3.2 提示覆盖必须同时报**候选数**

`untipped=0` 单独看毫无意义——枚举没找到控件时也是 0（空集通过）。
所以 `tipaudit.ps1` 同时打 `CANDIDATES=`；汇总行里给 `candidates_min=`，
本次基线 **37**（按钮 23 / 输入框 9 / 下拉框 5）。

### 3.3 不依赖 `X:` 盘符

那个映射每次 VM 重启都会丢（这轮踩了至少 4 次）。改成用
`robocopy \\Mac\backupRestore\tools\gui-check\ps H:\brwork\gui-check /E` 把脚本推进去再本地执行。

## 4. 验收（实跑）

### 4.1 冒烟

```
$ tools/gui-check/run.sh --quick
GUI_CHECK start vm=Windows 11 quick=1
  FITS font=14 lang=zh tab=1101 overlap=0 clipped=0 margin=514 cand=37 untipped=0
GUI_CHECK combos=1 clipped=0 overlaps=0 below=0 untipped=0 skipped=0 candidates_min=37
RESULT=PASS
```
耗时 **22.7 秒**。

### 4.2 全矩阵（建立基线）

```
$ tools/gui-check/run.sh
GUI_CHECK combos=20 clipped=0 overlaps=0 below=0 untipped=0 skipped=0 candidates_min=37
RESULT=PASS
```
耗时 **7 分 35 秒**；20 个组合 = 5 页签（1101 备份 / 1102 还原 C / 1103 第二系统 /
1104 安装 PE / 1105 还原数据）× 中英 × 14/18 号，**每个组合 0 裁切 0 重叠 0 越界 0 未挂**。

`margin` 呈现两个稳定值：**14 号 514、18 号 362**——字号变大内容下移，符合预期，
可作为下次对比的锚点（数字变了就该看一眼）。

### 4.3 回归保证：不误伤既有门禁

- `./build-win.sh`（无参数）仍正常构建 → 参数解析改造未破坏原行为；
- `bash -n` 语法检查通过（`build-win.sh` 与 `pre-push`）；
- 门禁第 8 项**默认关**，所以日常 push 不受影响（会打印一行「未启用」）。
