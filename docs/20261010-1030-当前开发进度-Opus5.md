# 当前开发进度

版本 **2.2.0**，开发测试版；模型 Opus 5（1M 上下文）。

本轮修复 [`可能的问题GPT6.md`](可能的问题GPT6.md) 14 项清单里最后两项确认未修的缺陷：

- **问题 9（P1）多任务共用固定载荷路径**：恢复载荷目录改为按任务 ID 隔离
  （`BackupRestoreRE\<任务ID>\`），路径收敛到唯一构造点，任务 ID 只接受规范 UUID 以防路径穿越。
  清理只删本任务子目录，父目录里还有别的任务载荷时原样保留。`ReBootEntry` 增加 `task_id`。
  连带修掉首次武装 `arm_one_shot` 会静默夺走他人一次性启动请求的问题（此前只有续跑路径严格拒绝）。
- **问题 13（P2）强制继续在重启后被静默撤销**：新增 `ImageAcceptance`，记录用户接受时镜像的
  **真实哈希与大小**并作为本任务权威值，旧副档仅留痕。例外绑定索引/哈希/大小，`Task::validate()`
  拒绝对不上的例外；确认之后镜像再被改动仍会被检出。

同时对 14 项清单逐项复核：第 1、2、4、5、6、7、8、12、14 项已在 2.1.0～2.1.9 期间修复或改变机制，
第 3 项维持已修；剩余第 10 项（控制文件仍固定 `S:\…`）与第 11 项（准备期缺统一回滚）未动。

本机 107 CLI + 40 core = **147 项通过**（2.1.9 为 142 项），严格 Clippy、格式检查与
Windows ARM64 发布构建全部通过，产物 2,212,864 字节。
