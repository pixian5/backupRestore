# 设置新增「界面字号」自选（v2.6.81）

> 模型：Hy4。时间：2026-10-30 02:35。
> 版本：**2.6.81**（行为变更：新增用户可设置的界面字号；布局高度改为按字号动态计算）。
> 关联：`docs/20261030-0209-界面基准字号12px提到14px…-v2.6.80-Hy4.md`（上一轮把字号从 12 提到 14）。

---

## 1. 需求

用户：*「增加设置，设置内可以自选字体大小」*。

上一轮把基准字号从 12 提到 14 之后，字号仍然是**写死**的。这一轮把它做成用户可选项。

## 2. 改动

### 2.1 字号管理（`crates/backuprestore-cli/src/dpi.rs` 新增）

| 项 | 说明 |
|---|---|
| 档位 | 12（小）/ **14（标准，默认）** / 16（大） / 18（特大），常量 `FONT_SIZE_CHOICES` |
| 合法区间 | 10–24，越界值一律退回默认（界面必须能起来） |
| 当前值 | `font_size()` 读原子量，`set_font_size()` 改 |
| 持久化 | `load_font_size()` / `save_font_size()`，写在共享的 `BackupRestore.settings.ini` 的 `font_size` 键 |
| **行距** | `line_height() = 字号 + (字号+5)/6`（锚点：12→14、14→17，与实测一致） |
| **文本块高度** | `text_block_height(行数, 附加量) = 行数 × 行距 + 附加量` |

**写入必须是「合并」而不是整文件重写**：该 ini 是共享文件，`failure_policy` 与
`dism_timeout` 也往里写。整文件重写会把它们的键**静默**冲掉——用户改一次字号就丢失失败策略，
这种丢失事后极难归因（`failure_policy` 的注释里记过同样的教训）。

### 2.2 界面（`settings_dialog.rs` + `native_gui.rs`）

- 设置窗口新增一行「界面字号：」+ 下拉框（ID 3111/3112）。
  窗口总高 560 → **590**，两个按钮 y 470 → **508**（原位置被字号行占用）。
- 保存时按**下拉框索引**取值，而不是解析文本——文本带本地化后缀（「14（标准）」/
  「14 (standard)」），解析它会把两种语言都写死；索引与语言无关。
- 保存后**立即生效**：`apply_font_size()` 用 `EnumChildWindows` 遍历主窗口所有子控件
  重设字体（`WM_SETFONT`），再调用 `layout_operation()` 重排。
- 启动时在**窗口创建之前**读回字号（否则会先用默认值画一遍再改，白闪一下）。

### 2.3 ★ 最关键的一点：行距与高度不许再写死

`gui_font()` 改成读 `font_size()`；`details_height` / `status_height` 与
`ID_SOURCE_DETAILS` / `ID_TARGET_DETAILS` / `ID_STATUS` 三处创建高度，
全部改为 `text_block_height(...)` 动态计算。

**这是第三次被同一类问题咬到**：
1. 2026-10-26：把行距写死成 12（漏了 tmExternalLeading），最后一行被切成半截；
2. 2.6.80：改了字号没同步改高度，同一现象重演；
3. 所以本轮直接把「字号→行距→高度」做成一条链，字号一变全链跟着变。

## 4. 遗留与已知问题

1. **设置窗口本身没能目视确认**。用自动化按控件编号点击「设置…」按钮（ID 1007）
   没有打开窗口，因此**下拉框长什么样、选项文字是否正常，尚未在实机上看到**。
   功能链路（写 ini → 启动 → 生效）是验证过的，但**界面外观待用户打开设置窗口确认**。
2. **18 档下有个别固定宽度控件可能截断文字**：字号 18 时截图里「压缩率」下拉框的
   文字看起来被右边缘截了一部分。这些控件的宽度是按 14 号字设计的固定值
   （压缩率下拉框重排宽度 280），大字号下需要跟着放宽——**本轮未改**。
   若用户常用大字号，下一轮应把这类固定宽度改为按字号计算。
3. 100% 缩放下仍未实测（与 2.6.79 同一个遗留）。

## 5. 过程里踩的坑

- **PowerShell 的 `ArrayList` 不能直接用 `-join`**：`$out -join "`n"` 对
  `System.Collections.ArrayList` 得到空字符串，导致把 `BackupRestore.settings.ini`
  **写成空文件**。改用 `@()` 数组。已在脚本里恢复默认内容并补回 `font_size`。
  ★ 教训：动共享设置文件前先回读确认内容，写坏了一并恢复。
- `SendMessageW` 的第 3 个参数是 `usize`（`WParam`），不是 `isize`——按索引设下拉框选中项时
  `CB_SETCURSEL` 要传 `usize`。

## 6. 一句话总结

字号从「写死的 14」变成「设置里可挑的 12/14/16/18」，改完立即生效、重启后保持；
顺带把「字号→行距→控件高度」串成一条链，免得第四次被同一个坑咬到。
