## 二、子系统职责边界与实现细节

新建自治模块 `crates/backuprestore-core/src/task_spec.rs`（358 行），精准收拢以下领域概念：

1. **镜像规格与用户例外记录 (`ImageSpec` / `ImageAcceptance`)**：
   - `ImageSpec`：记录 WIM 所在卷、相对路径、绝对路径、SHA-256、尺寸、WIM 索引编号及索引名；
   - `ImageAcceptance`：用户显式接受“镜像与副档哈希不符”时的鉴权例外记录；提供 `covers(index, actual_sha256, actual_size_bytes)` 判定契约，确保只有在索引、真实大小和真实哈希（不区分大小写）完全一致且哈希非空时才予以放行；
2. **目标卷规格与覆盖策略 (`TargetSpec` / `TargetRole` / `DestinationSpec`)**：
   - `TargetRole`：目标角色枚举（`ExistingWindows` / `NewWindows`）；
   - `TargetSpec`：记录目标卷、角色、菜单名、最小容量需求、`is_active_system`（当前运行系统判定）、`format_target`（格式化目标卷开关，缺省时默认为 `true` 保持历史兼容）以及 `overlay_no_acl`（覆盖式还原提权通道标记）；
   - `default_format_target()`：提供 serde 缺省值生成函数；
   - `DestinationSpec`：记录备份输出副档所在的卷与路径；
3. **引导规划与武装载荷清单 (`BootPlan` / `BootMode` / `PayloadManifest`)**：
   - `BootPlan`：引导模式（`ReturnExisting` / `AddSecondary`）、旧 BCD 哈希快照、引导菜单名与一次性启动标志；
   - `PayloadManifest`：WinRE 恢复载荷与环境散列清单（`task_id`、`recovery_sha256`、`task_sha256`、`original_winre_sha256`、`staged_winre_sha256`、`created_by_version`、`recovery_task_env_sha256`）；
4. **备份副档元数据与容量需求估算 (`BackupMetadata`)**：
   - 记录备份时间戳（创建/开始/耗时/速率）、环境信息（计算机名/版本/架构/构建号）、WIM 索引与哈希、已捕获用量、保留字节数等；
   - `required_target_size(&self) -> u64`：精确计算还原所需最小磁盘空间（取 `minimum_target_size` 与 `captured_used_bytes + reserved_bytes` 较大者）。
