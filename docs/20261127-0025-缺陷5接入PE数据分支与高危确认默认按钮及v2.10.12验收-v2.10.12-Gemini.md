## 一、本版背景与用户裁定

用户审阅了「进入 PE 对数据卷行为」「18 处确认框默认按钮」「备份取消状态栏文案」后，拍板执行如下四项（本版随代码改动从 `v2.10.11` 升版至 `v2.10.12`）：

1. **纠偏旧文档对缺陷 5 的不准确描述**：此前多份文档写的是「纯数据镜像选进入 PE 会先格式化数据卷再因缺系统文件报错」；实际对照 `pe_operation.rs` 的 `check_image()` 可知，对于非 `DataOverlay` 的操作，`preflight()` 在 `format()` **之前**就会执行 `dism /List-Image` 检查 `winload.efi` / `ntoskrnl.exe` / `config\SYSTEM`，纯数据镜像会在格式化之前被 `ImageMissingSystemFile` 拒绝，不会先把数据卷格空（VHD 用例 `no_write_on_reject` 的 `("two-index.wim", "restore", 1)` 实测亦佐证卷内容与序列号不变）。只有已包含这三类 Windows 标记但仍失败的镜像，才可能越过 `check_image()` 到达 `format()`。
2. **修复缺陷 5（方案乙）**：打通「还原数据到非 C 盘（`restore-data`）→ 进入 PE」的 `data`（`RestoreIntent::DataOverlay`）分支并透传 `format_target: bool`（勾选格式化才格式化目标卷，否则保留既有文件做覆盖还原，且任何 `DataOverlay` 均不修引导）。
3. **高危确认框改为安全默认（`No` / `Cancel`）**：仅高危确认框（破坏性确认、进恢复环境前最终确认、硬盘格式装 PE、删除旧索引、PE 桌面还原、未完成任务与立即重启询问）改为 `MB_DEFBUTTON2` 或 `MB_DEFBUTTON3`；低风险提示与保留默认值确认（覆盖还原二次确认、缺失档案提示、内存版装 PE）保持现状。同步在 `tools/gui-check/ps/uidlglist.ps1` 中输出按钮控件的 `def=True|False`。
4. **备份取消状态栏文案修正**：在破坏性确认上点击「否」后，`backup` 入口状态栏改写 `"用户取消了备份任务。"` / `"The backup task was cancelled."`。
5. **顺手修复工具遗留**：`tools/vm/rebuild-deploy.sh`、相关包装脚本与 `tools/vm/clean-fixtures.sh` 改为按运行标签落盘 `H:\brwork\build-$Tag.log`，不再覆盖旧构建日志；并针对跨进程 `GetWindowTextW` 读不到 `Edit` 运行时缓冲区的问题，让 `uidlglist.ps1` 对 `Edit` 控件改走 `SendMessageTimeoutW`（`WM_GETTEXTLENGTH` + `WM_GETTEXT`）读取实时文本。

## 四、本版未覆盖与已知限制（如实说明）

1. **PE 桌面真机重启动作**：当前测试虚拟机内未安装 WinPE，因此「从主界面 `restore-data` 点进入 PE → 重启进 PE 桌面 → 消费 `pe-requests/*.json`（`"data"` + `format_target`）」的真机重启环未在 WinPE 内目验；PE `"data"` 逻辑通过本机与 VM 单元测试以及 `ignored-acceptance.sh`（真实 VHD + DISM 应用）锁定。
2. **其余高危弹窗实机枚举**：本轮通过 `uidlglist.ps1` 在真机运行中抓取并确认了 `破坏性确认`（备份及还原 A/B/C 入口）与 `还原数据 → Windows RE 确认` 共两类弹窗的 `id=7 def=True`；其余 6 处改动了默认按钮的确认框（`pe_installer` 硬盘格式安装、`image_admin_window` 删除旧索引、`pe_desktop` 还原确认、`task_executor` 第 100/1139/1777 行未完成任务询问、系统盘进 RE 确认与开机续跑询问）通过代码逐处核对、交叉编译与 Windows 目标测试编译确认，未逐个弹窗实机触发。
3. **本版未重跑的既有大型用例**：全量 40 组合 `gui-matrix.sh`（本版仅跑 `--quick`，未改动控件坐标/字号）、`gui-backup.sh system`（需重启备份系统盘）、系统盘离线还原 `restore-existing`、`orphan-race.sh`、`data-guard.sh`、`pause-backup.sh`、`pause-restore.sh` 与断电/物理机矩阵。
