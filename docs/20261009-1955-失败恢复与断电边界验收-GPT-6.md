# 失败恢复与断电边界验收

版本 **2.1.9**，开发测试版。日期：2026-10-09；模型：GPT-6。

用户要求“除了扩展平台覆盖，全部做”。本轮范围为失败后的恢复保障、引导/恢复注册/清理/终态写入的断电边界及可复用验收脚本；不扩展 Windows 10、x64 或实体设备。C: 格式化还原、写入时断电及第二系统正常链路的上一轮证据见 [2.1.8 系统验收](20261009-0620-C盘断电自动续跑与第二系统完整验收-GPT-6.md)。

## 行为变化

- 恢复错误保留当前阶段、镜像、任务启动对象与载荷；不再直接标记 Failed（失败终态）或无条件导入旧 BCD（启动配置数据）。旧启动配置无法恢复已擦除的系统，还可能删除可用的恢复入口。
- 新增 RecoveryComplete（恢复已验证、待清理）阶段。该阶段重入仅清理，不再格式化或应用镜像。只有清理完成并持久化成功状态后，进度才显示操作完成。
- 状态更新先持久化事务，再写 task.json 与 status.json；加载任务时重放未完成事务。校验阶段跳转、任务身份和授权参数，拒绝事务换目标。
- 产品提供 `resume <任务根目录> <任务ID>`；恢复窗口支持“重试/取消”。重试前关闭旧进度窗口并等待线程退出，提示框主动取得键盘焦点；恢复入口先运行 Wpeinit（预安装环境初始化工具）。
- 自动重试次数上限只停止自动重启，不删除恢复材料。第二系统在擦除和引导修复前后也重新设置同一任务启动请求。
- 故障注入仅接受显式开发验收参数，正常任务不触发。运行中 BCDBoot（系统引导修复工具）检查点先实际启动工具，10 毫秒后暂停仍存活进程；工具已退出则报未命中。
