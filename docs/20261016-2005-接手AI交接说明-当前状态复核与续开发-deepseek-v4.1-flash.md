## 2. 复核清单（请逐条独立验证，不要只信本文）

### R1. 精确根因结论是否成立
- **主张**：`dism /Apply-Image` 覆盖式应用到**已含 Windows 的卷**时，
  在 `RestoreDirMetadata` 改写 `C:\Program Files\WindowsApps\*`（owner=`TrustedInstaller`）
  的目录元数据被拒 → `0x80070005` → exit 5。
- **可复核的证据**：
  - `docs/20261016-1413` §2：PE 内对照实验表（F: 成功 / C: 秒退）。
  - DISM 日志逐字段落（`RestoreDirMetadata:(2418): Access is denied`）。
  - "旁证"实验：`md`/`rd` 在该目录**成功**，只有改写元数据被拒。
- **怎么自己复验**：进 PE，对同一镜像分别 `/ApplyDir:` 到一个空数据卷与一个旧系统卷，
  对比 `X:\windows\Logs\DISM\dism.log` 的失败函数名。

### 3.2 新发现（**不是本轮引入，是本轮首次实机复现**）

**非终态任务会让 GUI 每次启动都重武装 `bootsequence`，把机器锁在 RE 里。**

- 失败任务（`stage=target-erased`）在失败前已 `rearm()`；失败后 `bootsequence` 未清。
- GUI 一启动检测到未终结任务 → 再次武装 → 重启 → 又进 RE。
- `abandon-task` 在擦除后**主动拒绝**，用户**没有自救出口**。
- **本轮救援后已确认**：清 `bootsequence` + 连测两次冷启动均正常进桌面。

→ 这直接抬高了待办 **B2「非终态任务自动收口」**的优先级（见 §4）。

### P0 — 强烈建议先做（有实机复现、用户会被锁死）

## 6. 环境与工具速查（VM 操作，踩坑索引）

### 6.1 宿主 → VM
- `prlctl exec "Windows 11" cmd /d /c '…'` = **SYSTEM + 管理员**，但：
  - **输出为 GBK**，管道过 `iconv -f GBK` 仍可能夹乱码 →
    **最可靠：让 VM 把输出写 `\\Mac\backupRestore\…`，宿主直接 `Read`**。
  - **路径反斜杠双写**；整条 `/c` 参数用 **bash 单引号**包裹（双引号会把 `\\Mac` 折成 `\Mac`）。
  - `cmd /d /c` 里 `& echo EXITCODE=%errorlevel%` 会展开成字面 `%0%` —— 用
    `setlocal` + `call echo %%errorlevel%%`。
- 截图：`prlctl capture "Windows 11" --file /tmp/x.png`（**改启动顺序前必先截图**）。

### 6.2 键盘注入（`tools/win-clicker/`）
- `vmkey.sh <key|combo>`：如 `enter` / `tab` / `esc` / `ctrl+p`。
- `type_text.sh "<text>" [delay]`：逐字注入。
  - ⚠️ **对 `{ }` 花括号不可靠**（实测打错成 `/tore`、吞空格成 `select volume4`）。
  - **可靠链（花括号场景必用）**：
    `echo <命令> > Z:\q.bat` → `type Z:\q.bat` **回读校验** → `call Z:\q.bat`。
  - ⚠️ 注入通道会抖动（回车乱喷），必要时 `cls` 清屏再操作。

### 6.4 WinRE / PE
- **RE 内 `prlctl exec` 不可用**（无 Parallels Tools）——只能读磁盘持久日志 + 键盘注入。
- **进 PE**：停 VM → `prlctl set "Windows 11" --device-bootorder "cdrom0 hdd0"` →
  start → **立即连续发空格 20s**（DVD 提示窗口很短）。
- **回 Windows**：停 VM → `--device-bootorder "hdd0"` → start。
- **清 `bootsequence`**（PE 内，见 6.2 可靠链）：ESP 一般挂 `Z:`，
  `bcdedit /store Z:\EFI\Microsoft\Boot\BCD /deletevalue {bootmgr} bootsequence`。
