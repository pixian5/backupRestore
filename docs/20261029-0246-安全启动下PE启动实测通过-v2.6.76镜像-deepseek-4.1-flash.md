## 二 PE 里留下的证据（`T:\exit-pe.log`，6867 字节）

「返回 Windows」在 PE 里现查 BCD（v2.6.75 的改动），日志摘录：

```
FAT volume: \\?\Volume{d08d796f-…}      ← 认到 ESP
mounted at S:
BCD file found
enum all exit code: 退出码 0
enum candidate: {78489a62-…} winpe=true  device=Some('X') path=\Windows\system32\winload.efi
…
live Windows loader: {a6273652-d15f-11f1-aa4b-ff70ff0b7794}
set default exit code: 退出码 0
delete bootsequence exit code: 退出码 1        ← 本来就不存在，良性
verify bootsequence: present=false
exit sequence done, rebooting (default restored=true, reboot without target=false)
```

回来后核验：`{bootmgr} default` = `{a6273652…}`（真 Windows 项），`secureboot` 仍为 `True`。

> 小观察：PE 里那一步先扫到一块 FAT 卷（没有 BCD），换到另一块 FAT 卷（ESP，GUID `d08d796f…`）才找到 BCD ——
> 这说明「按卷 GUID 找 ESP」的逻辑本机要跳过一次。不是缺陷，但排查时别被第一段 `BCD file NOT found` 吓到。
