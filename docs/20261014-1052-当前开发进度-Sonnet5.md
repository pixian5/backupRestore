  必须另加字段解耦（详见本轮文档 §三「走过的弯路」）。

## 本轮新增的机制结论

- **RE 里 `%SystemDrive%` 是 RAM 盘 `X:`**：「目标是否活动系统」只能在联机准备阶段判定并落盘带进 RE。
- **活动系统卷的 SYSTEM hive 被独占锁定**：两种共享模式都打不开，`probe_file` 对它会抛共享违例
  （os error 32，不是 NotFound）→ 绝不能对活动卷做文件探测。
- **加必填字段曾是破坏性变更**：`incomplete_tasks` 原先对所有任务（含终态）先反序列化，
  旧版终态任务缺字段会让新版完全无法建任务。已修。
- **`abandon-task`**（help 未列出）是清理 `prepared` 任务的正确路径：恢复 BCD + 按卷身份校验后删载荷。
