## 5. 新踩的坑（本轮实测）

1. **`cmd /d /c 'start "" …BackupRestore.exe'` 会把 GUI 子进程挂到 prlctl exec
   的 stdout 管道上 → prlctl exec 永不返回**（3 分钟无输出，只能 kill）。
   PowerShell `Start-Process` 不继承 pipe，一拍即回。
2. **PowerShell 5.1 `Add-Type` 的 C# 代码块里不能写 `IntPtr::Zero`**（C# 语法是
   `IntPtr.Zero`；`::` 是 PS 侧写法）。
3. **`(IntPtr)0x1B` 与 `(IntPtr)27` 在 PS 5.1 方法实参位都报「方法调用中缺少")"」**，
   必须 `(New-Object System.IntPtr 27)`。
4. **Session 0 GUI 对交互桌面不可见**：`prlctl capture` 拍到的是桌面不是程序窗口；
   给用户看的截图必须走 Session 1（`restart-gui-h.ps1`）。句柄级自动化
  （PostMessage/EnumWindows）在 Session 0 照常可用。
5. GBK 管道读 UTF-8 输出会乱码，涉及中文务必落盘 + PowerShell `Get-Content` 回读
   （沿用既有纪律，本轮再次验证）。
