## 版本状态

仓库版本 **2.6.11**。三分还原入口（A 到 C 盘离线 / B 数据到非 C / C 系统到非 C）此前已全部实机通过；本轮把「第二轮核查」（`20261017-0125`）列出的 **11 项处置建议全部落地**，并新增 RE 内最大化后台命令控制台。

## v2.6.11 落地的能力

1. **日志持久化（P0-1/P0-2）**：新模块 `session_log.rs`——RE/PE 会话检测在 RAM 盘时，自动把 `append_log` 双写到持久卷（选根顺序：卷 GUID → 同卷子目录 → `X:`）。RE 逃生日志、PE 会话 GUI 日志不再重启即丢。
2. **待续跑任务先问再做（P0-3/P1-6）**：`find_pending_boot_task`（只发现）→ 是/否询问框 → `resume_pending_now`（执行）；GUI 顶栏新增「取消待重启任务…」。**GUI 启动不再无声重启**。
3. **跨阶段自动重启总闸（P1-5）**：`MAX_TOTAL_RESUME_ATTEMPTS = 3` + 计数文件，与 per-stage 标记互补。
4. **进度窗 join 超时（P2-8）**：`close_and_wait` 30s 等不到窗口线程结束信号就 detach 并记日志，恢复链不再被永久钉住。
5. **启动项日志与 PE 重启兜底（P1-4/P2-9）**：三处「设 bootsequence + 重启」的 bcdedit 完整输出统一落 `boot-sequence.log`；`wpeutil reboot` 失败回退 `shutdown.exe`，双失败弹框。
6. **PE 桌面建窗失败退路（P1-7）**：先开最大化 cmd 再让用户选「重启 / 留在 PE」。
7. **RE 内最大化后台命令控制台（新需求）**：`CreateProcessW` + `SW_SHOWMAXIMIZED` 起 `cmd.exe /k title BackupRestore recovery console`；本程序弹框 `MB_SETFOREGROUND` 保持前台。**实机截图证实**（`.test-artifacts/v2611-re-01.png`）。
8. **杂项收敛（P2-10/P2-11）**：删 `C:\brgui-trace.txt` 探针；`system_choice_log` 并回 `append_log`；PE 安装 `fs::copy`/`create_dir_all` 失败落日志；`fltmc` 输出落盘。
