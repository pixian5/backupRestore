## 实测中遇到的问题

1. PowerShell（命令脚本环境）`Start-Process -ArgumentList` 拆分带空格的菜单名称，最初请求以 `unknown prepare option: Secondary` 退出，未创建任务。脚手架显式引用菜单名称后修正。
2. 新磁盘热插拔后的首次冷启动改变磁盘编号。旧任务停在 `boot-requested`，按冷启动后的身份重建任务，并归档旧任务；没有放宽产品身份检查。旧任务编号为 `0034c543-e4d4-4911-95e8-f25c769316f9`。
3. Windows PowerShell 对 `@(Get-Content ... | ConvertFrom-Json)` 的数组包装导致夹具摘要比较假失败。脚手架改为先赋值再逐项遍历后复核通过；不能把脚手架错误记为主系统受损。
4. 快照占用使删除大文件后宿主空间未同步回收。续跑前必须核验实际宿主空闲量，不能仅累计已删除文件大小。
