## 当前版本：v1.9.0

### 本轮完成更新（2026-09-30 15:30）

1. **更正“必要时代原恢复环境”笔误**：
   - 将 `main.rs` 及相关测试用例中的文字统一更正为“准备备份环境（挂载卷、校验、必要时还原恢复环境）”。

2. **根除 RE 程序内文字乱码**：
   - 为所有 DISM 子进程调用统一增加 `/English` 参数，从源头确保输出纯 ASCII 文本，规避代码页与文本匹配错位。
   - 新增 `decode_windows_bytes`，对非 UTF-8 字节自动调用 Windows API `MultiByteToWideChar`（OEMCP/ACP，即 CP936/GBK）无损转换为 UTF-16/UTF-8，彻底解决控制台中文导致的“锟斤拷”乱码。
   - GDI 字体创建中指定 `GB2312_CHARSET`（134），确保 WinRE 精简环境下即使缺少微软雅黑也能强制正确回退至中文字体渲染。
   - 过滤详情框中无负载的纯 `[stdout]` / `[stderr]` 标签行。

3. **进度条调整为显示当前阶段进度**：
   - 恢复进度窗口的进度条由原先折算的综合总进度改为直接反映当前正在执行步骤的内部进度（如 DISM 1%~100% 直观满条）。
   - 在 `StepTracker` 中增加步骤推进时的百分比重置，避免上一步进度残留。

4. **版本号升级**：
   - 从 `1.8.19` 按逢十进一规则进位至 **`1.9.0`**（VERSION、Cargo.toml、Cargo.lock 均已同步）。
