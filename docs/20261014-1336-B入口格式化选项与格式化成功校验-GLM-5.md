# B 入口「格式化目标分区」选项与格式化成功校验（v2.5.2）

> 模型：GLM-5｜版本 **2.5.1 → 2.5.2**｜用户 2026-10-14 拍板：「还原数据到非 C 盘」应该格式化，且要判断格式化是否成功；界面要有显式的格式化选项；测试先手工格式化验还原链路，再测程序自带格式化。

## 1. 需求与设计变化

原设计（2.5.0）：B 的格式化行为藏在通道里——在线=不格式化（覆盖）、离线=格式化。用户指出问题：①还原的正确语义应是格式化后写入；②格式化必须校验成功；③界面上看不到格式化与否的选项。

新设计（2.5.2）：

- **B 入口新增「格式化目标分区（清空目标卷后写入镜像）」复选框，默认勾选**（还原的完整语义）；取消勾选=覆盖式应用（镜像没有的文件保留）。
- **在线通道勾选时**：diskpart 快速格式化 → **校验格式化成功** → 再应用镜像。校验复用 `verify_formatted_volume`：同分区 GUID/几何不变 + NTFS + **卷序列号必须改变** + 根目录可读——任何一项不过即中止，**格式化没成功绝不往旧数据上叠镜像**。
- **离线通道恒格式化**（RE 内原有行为），复选框只对在线生效（tooltip/提示文案写明）。
- A/C 入口恒格式化（重建系统/装系统本来就必须），无需选项。

## 2. 改动清单

- **阶段 1a（手工格式化 + 纯还原链路）**：宿主侧先用 diskpart 手工格式化 T: → GUI「还原数据到非 C 盘」在线通道、**取消勾选格式化**（测试钩子 `"format_target": false`）→ 还原。判定：内容一致；程序未再格式化（Online.log 无格式化行、序列号与手工格式化后一致）；BCD 不动。
