## 一、改造背景与目标

在 BackupRestore 此前的架构重构中，`crates/backuprestore-cli/src/native_gui.rs` 已成功从 11,067 行解耦至 2,540 行（-77.1%），并完成了全仓生产代码 0 unwrap 零 panic 免疫改造。然而，另一个核心巨石——CLI 主程序入口 `crates/backuprestore-cli/src/main.rs`（初始 6,287 行）依然高度耦合：
1. **进程运行器与日志管理**：子进程派生、超时轮询、管道重定向、尾部截获等混在主入口；
2. **BCD 维护与引导项调度**：BCD 快照恢复、默认项原子翻转、第二系统菜单编排、休眠对象回收等引导维护逻辑交织；
3. **恢复环境卷管理器**：`RecoveryTask.env` 解析、跨重启卷 GPT 稳定身份比对、`mountvol`/`diskpart` 挂载与候选字母循环分配、DiskPart 格式化脚本生成等体积超千行；
4. **恢复引擎状态机**：WinRE / PE 宿主循环、断电续跑重入、DISM / wimlib 还原流转、自检与连续失败自动逃生等长达两千余行。

本次重构目标：**按功能领域完整切分四大专业自治模块，让 `main.rs` 纯粹回归 CLI 命令行参数解析与分发入口，实现整体架构高内聚、低耦合。**

---

## 二、四大自治模块详细切分

### 1. `process_runner.rs`（255 行）
- **职责**：封装通用的进程启动、超时控制与日志记录。
- **核心组件**：
  - `run_logged` / `run_logged_timeout`：标准输出文件挂载与超时强杀；
  - `capture_logged` / `run_output_logged`：内存流管道截取与退出码解析；
  - `output_tail_summary` / `stream_to_log`：日志尾部摘要提取；
  - `run_command`：带 `BR-APL-010` 契约码的 CLI 通用命令执行通道。

### 2. `recovery_bcd.rs`（528 行）
- **职责**：恢复完成后的 BCD 引导项维护、默认项校验与第二系统引导菜单编排。
- **核心组件**：
  - `BcdBootManagerState`：启动管理器快照状态与回读解析；
  - `verify_default_entry_switch`：默认启动项切换与防回跳校验；
  - `append_secondary_menu_entry`：第二系统 UEFI 引导项注入与显示名冲突处理；
  - `clean_orphan_resume_object`：孤儿休眠恢复对象（resumeobject）回收；
  - `bcd_identifier_from_line`：跨语言 BCD GUID 行解析。

### 3. `recovery_volume.rs`（1,172 行）
- **职责**：恢复环境（PE / WinRE）下的卷挂载、盘符分配、身份复核与分区格式化。
- **核心组件**：
  - `read_env_file` / `verify_task_identity_env`：`RecoveryTask.env` 键值读取与跨重启卷身份比对；
  - `mount_env_volume` / `assign_volume_letter`：`mountvol` 优先、`diskpart` 兜底的候选盘符分配；
  - `resolve_volume_letter` / `letter_for_partition`：跨重启动态盘符寻址；
  - `diskpart_format_script` / `format_target_partition`：目标分区 DiskPart 快速格式化与安全核验；
  - `resolve_efi_root_for_recovery`：数据卷免 ESP 路由与系统还原前置 ESP 探测。

### 4. `recovery_engine.rs`（2,208 行）
- **职责**：恢复宿主运行状态机与恢复执行循环。
- **核心组件**：
  - `recover_windows`：多阶段恢复主状态机（`Preflight` -> `Capturing`/`TargetErased` -> `ImageApplied` -> `BootRepaired` -> `RecoveryComplete`）；
  - `recover_env` / `recover_env_interactive`：恢复环境自动拉起、连续失败阈值判定、超时自动逃出（`auto_escape_to_windows`）；
  - `launch_background_console`：WinRE / PE 下常驻后台最大化命令提示符，提供终端自救出口；
  - `complete_recovery_cleanup`：终态自检（`append_restore_selfcheck`）与载荷清理；
  - `resume_task`：显式任务续跑。
