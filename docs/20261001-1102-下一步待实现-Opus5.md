## 一、已定、不再悬置的取舍

1. 必需身份、角色、镜像或容量证据未知即拒绝写入；用户确认不豁免未知，也不能将 ESP（EFI 系统分区）或工作区变成普通格式化目标。
2. 主系统从任务的稳定身份确定；BCD（启动配置数据）默认项与加载器集合只是交叉证据。第二系统重装可覆盖获明确授权的其他系统卷，不得因此开放主系统。
3. 文件探测使用保留错误的 Rust 接口；存在性与任务角色分开。不是把 `.is_file()` 换成另一个会吞错的布尔接口。
4. 现场身份、当前编号、角色矩阵、写许可与实际命令必须贯通所有可达破坏性入口，不能把后一半推迟后就宣布保护完成。
5. 不可变计划与单一运行状态分离，失败请求不能靠“未改名 .done”自动重新执行。
6. 候选副本保留；性能优化只省重复读取，不降严格校验强度；空间不足不退回就地覆盖旧备份。
7. 短探针有限时，长写盘操作不按固定十分钟或日志静默强杀；取消需要确认进程和现场收敛。
8. 单机写任务先串行；每次新的启动/PE 部署变更前独立新快照，不复用一个旧快照覆盖多次事务。

## 二、后续实施批次

### A：契约、只读复现与测试替身

- 固化意图、保护角色矩阵、目标绑定确认、`WritePermit`（写许可）、`StepResult`（步骤结果）与运行状态协议。
- 建立卷解析、镜像检查、命令、状态、BCD 和时钟替身，记录参数与调用顺序。
- 先以临时目录验证三态、路径差异和旧输出残留；用原生隔离测试确认尚未验证的命令解释器重定向假设。不运行旧 `restore`（还原）命令来充当只读观测。
- 门槛：每个必需检查失败后，格式化、应用、引导写入和重启调用均为零。

### B：执行器与状态基础（W08、W06、W12）

- 先迁移只读命令，验证输出同源、分块解码、取消、结果未知和日志失败。
- 新协议计划不可变、运行状态唯一权威；旧协议活动任务先备份，不静默升级执行。
- 武装先记意图，回读后才记已武装；任一外部动作成功、结果落盘前中断都要有对账规则。

### C：统一写盘入口（W01～W04、W09）

- 物理分区和卷两层发现，覆盖无盘符/未格式化目标；不支持的布局明确拒绝。
- 同一许可产生实际磁盘编号和路径；检查后地址变更撤销许可。
- 镜像、索引、内容、容量、角色和授权都在第一次不可逆操作前核验。
- 三入口使用同一结果规则；系统还原缺关键文件不能按数据成功；所选非 1 索引必须保留。
- 失败请求持久标为待处理，重复请求不重新格式化；控制文件写失败时禁止武装。

### D：备份发布与启动资源（W10、W11、W05、W07）

- 候选上完成索引和副档，持久发布清单/旧代/读门禁共同处理每个替换窗口。
- 任务私有载荷、单机互斥、所有权清理、精确 BCD 目标及一致快照。
- 目标存储锁定时受阻退出，不转去未知系统存储导入；清理失败不能导致重新格式化。
- 系统不可启动时验证恢复入口实际可达；不擅改默认启动策略来承诺无人值守续跑。

### E：分层验收，不以构建代替实机

- 本机测试及 Windows ARM64（64 位 ARM 架构）构建通过后，再进行 Windows 原生隔离测试、专用测试卷、PE/WinRE（恢复环境）事务。
- 总方案 T01～T45 与局部 P01～P09 分别落测试证据；它们目前都是待验收设计。
- 每次启动配置、默认项、一次性序列、WinRE 注册或 PE 部署变更前创建并核验新快照；PE 内手动变更/返回也按新的操作处理。最多保留最近两份符合项目规则的快照。
- 系统卷实机测试需该轮明确授权。对照证据可以在同一计划中收集，但不能让不同变更共用一次快照授权。
- 新程序/恢复程序/协议/真实注入件一致后才部署验收；没有新旧混合载荷。
