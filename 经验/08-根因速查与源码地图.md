## 2. 关键源码位置（grep 符号导航）

**core（lib.rs）**：`Stage` 11 阶段枚举｜`commit_state()`/`state-transaction.json` 事务重放｜`TargetSpec.is_active_system`/`overlay_no_acl`（serde default 兜底 false）｜`incomplete_tasks()`（先读 status.json 定性）｜`verify_formatted_volume` 判据（operation_safety）｜`pe_safety::probe_file`（活动卷 os error 32 短路）

**CLI**：
- `boot_entry.rs`——`dos_device_of()`(QueryDosDeviceW)、ramdisk 写入点、`remove_entry_objects`（删除容错+枚举回读范式）、载荷按任务 ID 隔离
- `boot_menu.rs`——`block_is_loader_for`（本地化 OR 语义）、`DefaultPolicy`/`set_default_policy`、`object_exists_in_enum`（结构性判据）
- `main.rs`——`preserve_primary_boot_manager`/`cleanup_orphaned_secondary_resume_objects`/`assert_boot_default_preserved`、`resume_pending_boot_task`（恰 1 个）、`can_abandon_before_target_write`、`stage_resumable_after_interruption`、`EXPECTED_WINRE_SHELL` 之外 host 侧准备链
- `windows_prepare.rs`——`esp_identity_without_drive_letter()`（ESP 零盘符三重校验、多候选拒绝）、`is_active_system` 落盘、自毁保护文案、`re_staging.volume`
- `secondary_registry.rs`——`gpt_mapping()`（DMIO:ID: 小端）、`repair()` 四步
- `online_operation.rs`——在线事务/回读、STEP 3.5 盘符绑定、sidecar 同步
- `pe_operation.rs`——pe-requests/*.json、`winre_registration` preflight
- `winre_registration.rs`——恢复关联核验（缺 reagentc 时整体失败=P5）
- `windows_command.rs`——作业对象+进程树终止、`quote()`（标准 MSVCRT 转义，POC 在 cmd 直跑遇到的 `"F:\"` 吞参坑在本通道不存在）
- `wimlib_apply.rs`（v2.6.25 新）——`WIMLIB_EXE`/`WIMLIB_DLL` 常量、`wimlib_args()`（命令形状单测锁定）、`locate_wimlib()`（缺失报错两文件名、不回退 DISM）、`apply_no_acl()`（失败即 Err）
- `recovery_progress.rs`——进度上报、ID_CMD_BUTTON/VK_K、`spawn_detached_interactive`
- `text_parsing.rs`——本地化解析（**唯一 macOS 也编译可单测的纯逻辑层，测试都下沉这里**）、`decode_windows_bytes`、`parse_boot_manager_state`
- `native_gui.rs`——入口分流/格式化复选框/`--skip-format` push、自毁保护、tab 布局、日志路径

**tests**：`cargo test` macOS 只覆盖 non-windows 部分；实机验收链在 `tools/acceptance/`（run.py/case.ps1/system.ps1/errors.ps1）；GUI 自动化在 `tools/win-clicker/`（br-agent-tcp.sh 0.2s/步首选、vmkey.sh send-key-event、restart-gui-plain/restart-gui-h.ps1、br-enum-dlg/br-focus-gui）。

## 3. 结构不变量（改代码前先对表）

- WinRE shell 契约内嵌于二进制，构建前断言模板相等；
- 载荷哈希五件套：注入前核对→注入后核对→任务 WIM 内 `Recovery.exe` 版本可验；
- 断电四件套：载荷任务隔离/`commit_state()` 每次 load 前重放/原子写 MoveFileExW(WRITE_THROUGH)/每 Stage 一次重试额度（claim_boot_resume_attempt）；
- `resume` 幂等：`RecoveryComplete` 重入只清理不重做磁盘操作；
- 三道纪律：不信退出码/写完回读/簿记与镜像同步（本库反复出现，因为每个 bug 都是违反它的产物）。
